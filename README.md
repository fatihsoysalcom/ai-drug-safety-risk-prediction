# AI Drug Safety Risk Prediction

This example demonstrates how a simple AI model can be trained to predict potential drug safety risks. It simulates analyzing various factors like chemical properties and patient data to classify new drug-patient scenarios as either low or high risk. This illustrates the article's concept of using AI for proactive pharmacovigilance and catching risks before the first dose.

## Language

`python`

## How to Run

1. Ensure Python 3 and scikit-learn are installed (`pip install scikit-learn numpy`).
2. Save the code as `main.py`.
3. Run from your terminal: `python main.py`
